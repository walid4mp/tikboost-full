# Screenshots

ضع في هذا المجلد لقطات الشاشة الأربع للتطبيق بالأسماء التالية بالضبط:

| الملف            | يقابل الخطوة        |
|------------------|---------------------|
| `screen-1.png`   | إنشاء الحساب        |
| `screen-2.png`   | جمع النقاط          |
| `screen-3.png`   | إنشاء حملة          |
| `screen-4.png`   | متابعة النتائج      |

**المواصفات الموصى بها:**
- النسبة: **9:16** (portrait)
- الأبعاد: **1080 × 1920 px** (أو أقل حتى **720 × 1280**)
- الصيغة: **PNG** أو **WebP**
- الحجم الأمثل لكل صورة: **< 300 KB** بعد الضغط

سيقوم الموقع تلقائيًا بعرض الصور فور رفعها، وإن لم توجد ستظهر بطاقة عنصر نائب (placeholder) جميلة بدلاً منها.
